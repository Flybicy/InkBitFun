MiSans Fonts Notice

Non-Apple OpenBitFun GUI distributions use unmodified copies of Xiaomi's MiSans
fonts so Simplified Chinese body, control, and display text renders identically on
Windows and Linux.
Copyright Xiaomi Inc. (小米科技有限责任公司).

Bundled faces: MiSans Regular (400/500), MiSans Semibold (600), and MiSans
Bold (700).
These are the unmodified official WOFF2 exports from Xiaomi's package:
https://hyperos.mi.com/font-download/MiSans.zip
The package page: https://hyperos.mi.com/font. Retrieved: 2026/09/30.

Regular carries the Simplified Chinese body and control weights, while
Semibold and Bold preserve the display weights. macOS keeps the apple-system profile,
so it ships no product text font at all and uses a locally installed MiSans when
present.
